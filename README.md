# Neovim configuration

## Installation

make sure to back up or delete ur old nvim config before installing this

```sh
# OPTIONAL: Back it up
mv ~/.config/nvim ~/.config/nvim.backup

git clone https://github.com/iUnstable0/nvim-config.git ~/.config/nvim
```

## Keymaps

Leader key for this config is `space`. you can press it once (not hold) to open the menu to view actions
press `=` to view the cheatsheet

## Plugins

| Plugin | Purpose |
| --- | --- | --- |
| `catppuccin/nvim` | Color scheme |
| `folke/which-key.nvim` | Discover keymaps |
| `nvim-tree/nvim-tree.lua` | File explorer |
| `nvim-tree/nvim-web-devicons` | File icons |
| `kylechui/nvim-surround` | Add, delete, and change surroundings |
| `christoomey/vim-tmux-navigator` | Navigate splits and tmux panes |
| `szw/vim-maximizer` | Temporarily maximize a split |
| `lambdalisue/vim-suda` | read/write protected files with password |
